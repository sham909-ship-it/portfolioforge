# 🚀 PortfolioForge AI

A modern **portfolio generator web application** that allows users to create professional portfolios instantly using customizable templates.

---

## 🌐 Live Demo



---

## 📌 Project Overview

PortfolioForge AI is a web-based platform where users can:

* Enter their personal and professional details
* Choose from multiple portfolio templates
* Instantly generate a fully structured portfolio

This project focuses on **user experience, dynamic rendering, and UI design**, simulating a real-world product.

---

## ✨ Features

* 🎨 Multiple portfolio templates (Minimal, Dark, Creative, Professional, Sidebar)
* ⚡ Instant portfolio generation
* 🧱 Structured sections:

  * About
  * Education
  * Experience
  * Skills
  * Projects
  * Social Links
* 🔄 Regenerate / Edit option
* 💬 Landing page with features & user reviews
* 📱 Responsive and clean UI

---

## 🛠 Tech Stack

* HTML
* CSS
* JavaScript

---

## 🧠 How It Works

1. User navigates to the builder page
2. Inputs personal and professional details
3. Selects a preferred template
4. JavaScript dynamically renders a portfolio layout
5. The selected template is applied using modular template functions
